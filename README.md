## How to open

1. Download or clone this repository.
2. Open the notebooks using Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the cells in order.

## Python libraries used

The notebooks use libraries including NumPy, pandas, Matplotlib, Seaborn, SciPy, scikit-learn, statsmodels, and cryptography.

Install the listed libraries with:

```bash
pip install -r requirements.txt
```

## Dataset note

Some notebooks expect CSV files to be uploaded or available separately (for example, sales, Iris, Hotel, customer, salary, and Mall Customers datasets). Those datasets were not included in the ZIP archive supplied for this repository, so provide the required files before running the corresponding notebooks.
